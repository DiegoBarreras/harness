# personal-ai-harness

Harness personal para desarrollo asistido por agentes, con Zed como entorno principal. La arquitectura prevista separa al **Orchestrator** (coordinación), **Builder** (implementación) y **Verifier** (verificación), con **Jev/TypeSafe** como decision layer y reglas deterministas del harness para los thresholds.

El proyecto está actualmente en fase de preparación de V1. No hay funcionalidades implementadas.
